# Yousef Douhan — Portfolio

Personal portfolio website of **Yousef Douhan**, Backend Developer (PHP & Laravel).

- Bilingual: English / العربية (RTL), switchable from the navbar
- Pure HTML, CSS and vanilla JavaScript — no build step
- Clean motion: scroll reveals, animated circuit traces, typewriter, counters, magnetic buttons
- Respects `prefers-reduced-motion`

## Structure
```
index.html
css/style.css
js/main.js
assets/me.jpg
assets/favicon.svg
```

## Run locally
Open `index.html` in a browser, or serve the folder:
```
npx serve .
```
